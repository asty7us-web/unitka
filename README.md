# Юнитка

Калькулятор юнит-экономики Wildberries, Ozon и Яндекс Маркета: https://asty7us-web.github.io/unitka/

- **Расчёт** — цена и скидки, себестоимость партии, комиссия, эквайринг, логистика с учётом выкупа, хранение, реклама (ДРР), налоги (УСН, АУСН, ОСНО, НДС). Итог: прибыль с штуки, маржа, ROI, безубыточная цена, цена под целевую маржу, «что если поменять цену».
- **Факт и цена** — фактическая экономика каждого артикула из панелей и пересчёт под новую цену. Данные лежат только зашифрованными (`fact.enc.json`, AES-256-GCM), открываются паролем.
- **Мои расчёты** — сохранённые расчёты на устройстве, сравнение, перенос файлом или ссылкой.

Один файл `index.html`, без сборки и внешних библиотек. Данные пишет скрипт `unitka.py fact`, руками не править.
